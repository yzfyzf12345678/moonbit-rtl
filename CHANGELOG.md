# Changelog

## 0.1.2

- Added deterministic preprocessing, four-state vectors, and fixed-point RTL simulation.
- Added hierarchy, timing, coverage, intermediate IR, advanced rules, LSP, and project configuration APIs.
- Added query, normalized netlist, verification-plan, release-report, and trace replay tooling.
- Added cross-target boundary tests and raised the CI production-source inventory gate to 20,000 lines.

## 0.1.0

- Added a Verilog-2001 subset lexer and module parser.
- Added AST types for modules, ports, signals, assignments and always blocks.
- Added duplicate, driver, reference and diagnostic rules.
- Added terminal and JSON diagnostic renderers.
- Added executable example, tests, proposal notes and cross-platform CI.
